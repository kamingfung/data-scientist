# Consulting & Executive Communication

Deliver executive readouts, status updates, Q&A responses, and consulting-grade slides top-down so a busy decision-maker grasps the takeaway in under 30 seconds.

- See [references/summaries-and-qa.md](references/summaries-and-qa.md) for summary formulas, status updates, table transforms, and Q&A scripts.
- See [references/slide-design-spec.md](references/slide-design-spec.md) for 16:9 consulting slide geometry, typography, palette, and exhibit patterns.
- For a deck built as HTML from data, use [../html-data-deck/SKILL.md](../html-data-deck/SKILL.md); its density, palette and theme rules replace the ones in section 3 here.

## 1. Executive Summaries, Updates & Q&A

- **Headline first:** open every summary, email, status update, or spoken answer with the single most important decision or takeaway.
- **Cut ~25% on revision:** strip preamble, throat-clearing, and chronological recaps (`"First we checked X, then Y"`).
- **Write with conviction:** drop hedge words (`"kind of"`, `"sort of"`, `"just"`, `"I think"`, `"maybe"`) and state conclusions directly.
- **Structure status updates:** lead with `Status / Decision`, then `What changed` (quantified), then `Blockers / Owner / Next date`.
- **Use concrete analogies:** pair abstract numbers with one relatable visual or scale comparison (`"~72M acres — the size of Iowa & Illinois combined"`).
- **Pause after key points:** stop cleanly after delivering a headline number or answer instead of trailing off with caveats.

## 2. Storylining & Deck Flow

- **Follow the 4-stage deck arc:** Cover → **Executive Synthesis** (`3–4` theme cards on Slide 2) → **Agenda / Section Divider** (active section highlighted) → **Numbered Evidence Slides** (`1.`, `2A.`, `(1/3)`).
- **Use a 3-slide mini-arc per topic:** *Framing / Scope* slide (`N` drivers) → *Quantified Evidence* slides (`1` insight per slide) → *Implications / Actions*.
- **Draft the action-title storyboard first:** write Slide 1 to Slide N titles as complete sentences; verify the titles alone read as a coherent executive summary.
- **Write the "Final Slide" upfront:** place a decision scorecard (Options × Criteria) early so executives see the trade-offs immediately.

## 3. Slide Ledes, Content & Visual Spec

- **Make the action title the lede:** state `Subject + Active Verb + Quantified So-What`, never a topic label.
- **Scope with the subtitle (`y = 0.99"`):** state the data lens and unit; label every chart with `Metric, Unit`.
- **Deliver prose as `[Bold Lead-in]: [1–2 line insight]`:** use scannable cards (`Pain Points` / `Solutions` / `Results`, or `Context` / `Impact`), never bullet walls.
- **Cap density:** target `<=12` slides in the main deck (details in appendix), `<=4` bullets per card/slide, and `<=5–6` words per bullet.
- **Apply the 16:9 consulting grid:** `13.33" × 7.50"` canvas, `0.61"` margins, **Georgia** for cover/dividers/kickers, **Arial** for action titles (`14–16 pt`), body (`10–14 pt`), and `Source:` footers (`7–8 pt`).
- **Use the corporate palette:** Deep Navy (`#051C2C`), Electric Blue (`#2251FF`), Cyan (`#00A9F4`), Slate (`#303D48`), and borderless `#E6E6E6` / `#EDF6F2` cards with thin accent bars.
