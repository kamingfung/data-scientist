# data-scientist

Self-contained agent plugin for data science engineering, structured problem solving, and corporate/consulting communication.

## Skills (7)

| Skill | Scope |
| :--- | :--- |
| [developer-guides](skills/developer-guides/SKILL.md) | Python/Kedro code style, parameters, Pandera schemas, unit tests, logging, parallelism, visualization, technical writing, and agent defaults |
| [code-review](skills/code-review/SKILL.md) | PR and branch review workflow plus full engineering checklist |
| [worktrees](skills/worktrees/SKILL.md) | Git worktree creation, usage, and cleanup |
| [structured-problem-solving](skills/structured-problem-solving/SKILL.md) | Hypothesis-driven decomposition, MECE `if/then` issue trees, 80/20 drill-down, pre-mortems, and top-down synthesis |
| [sharp-agent](skills/sharp-agent/SKILL.md) | How fast to move versus how much to verify: a task loop, a speed dial, guardrails, and references for coding, research, long tasks and incidents |
| [html-data-deck](skills/html-data-deck/SKILL.md) | Data-driven HTML slide decks: title-only outline, action titles, inline SVG charts, a source for every number, builders, and a three-pass review |
| [consulting-communication](skills/consulting-communication/SKILL.md) | Executive summaries, stakeholder updates, Q&A delivery, consulting slide storylining, and 16:9 visual design specs |

## Installation

Symlink this repository into `~/.gemini/config/plugins/data-scientist`:

```bash
ln -sfn /Users/fkm/GitHub/data-scientist ~/.gemini/config/plugins/data-scientist
```
